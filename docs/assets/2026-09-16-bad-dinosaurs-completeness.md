# Bad Dinosaurs collection completeness check

Checked 16 September 2026 against the user's supplied screenshots, the indexed [Dinopedia creature list](https://dinopedia.fandom.com/wiki/Bad_Dinosaurs), and the actual profiles in `src/data/dinosaurKnowledge.ts`.

The supplied list contains **16 entries**. The game implements **10**. **Six are absent**, so the earlier collection was incomplete. The two supplied screenshots show the same list. Tyrannosaurus is already represented by Tyrannosaurus rex; it is not another missing entry.

Dinopedia is a fan-maintained checklist, not an official production species register. Matching its list establishes these omissions relative to the requested checklist; it does not independently confirm every cartoon-to-species identification or every episode appearance. Keep uncertain matches qualified.

Already implemented: Ankylosaurus, Brontosaurus, Pachycephalosaurus, Parasaurolophus, Pteranodon, Quetzalcoatlus, Stegosaurus, Triceratops, Tyrannosaurus rex and Velociraptor.

Completing this checklist means accounting for **15 named taxon entries plus one unidentified character**, rather than describing all 16 as dinosaurs. Existing pterosaurs also retain their proper labels.

This check updates the collection documentation only. The six missing entries do not yet have game profiles or a complete set of local cartoon, reconstruction and clue artwork. Adding them requires broadening the current `Dinosaur`/`Pterosaur` classification and two-period data model, obtaining show references for the missing character designs, and supplying appropriate shared period/food/habitat art plus individual and themed generic ability art. Donnie needs a deliberate unknown/speculative treatment rather than fabricated learning facts.
