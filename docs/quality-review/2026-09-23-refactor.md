## Findings and changes

1. **Agenda presentation was duplicated.** DayAgenda and SchoolEvents independently owned their section styles, list structure, artwork, title and clock placement. A shared `AgendaList` now owns that presentation, while each caller supplies its domain-specific entries. Its timing union explicitly distinguishes ranges, single times, all-day events and missing times. This removes the detected clone and gives future layout fixes one implementation. The current colors, centered artwork, all-day indicator, dates on overnight events and expansion interactions remain intact.

2. **Drag scrolling spread one gesture's lifecycle across four mutable refs.** Native event registration, gesture state and cleanup now live together inside the effect, with separate abort scopes for the component and active gesture. Drag completion, blur and unmount release listeners and restore the previous text-selection setting. ResizeObserver already covers element resizing, so the duplicate window-resize listener was removed. The unused theme prop and dependency were removed from the component and both callers. DragScrollRegion's locality risk falls from 100 to 84; its reported Halstead effort falls from approximately 301,205 to 193,887.

3. **Weather listeners belonged to individual subscribers although requests and snapshots belonged to cities.** Each city now owns one set of browser listeners and one interval. The final unsubscribe releases them, with the existing microtask grace period for React StrictMode resubscriptions. Refresh eligibility and request execution are separate named operations in the same module. Stale data, retries, city isolation, midnight refresh and cancellation behavior are preserved. The refresh coordinator's cognitive complexity falls from 16 to 11; the separate request function measures 5. This extraction improves the size of each responsibility without claiming that all of its decisions disappeared.

4. **Quiz state declarations repeated the same fields for every activity.** A prefix map and shared mapped type now generate the completed-at/outcome fields. The discriminated union still restricts each activity to its own stored fields, including Fractions. Internal schemas and types are private where no external consumers exist. Task templates are flattened, removing the redundant `extras` container and repeated test categories while retaining explicit, checked defaults. Chore mode types reuse the task-type definition instead of maintaining a second union.

5. **Routing encoded a lookup table as a multi-case switch.** An explicit Map now associates canonical and legacy paths with the existing lazy loaders. It preserves trailing-slash behavior and unknown-route handling, including names inherited by plain objects such as `constructor`. The resolver's cyclomatic complexity falls from 14 to 3.

6. **Small UI and API redundancies obscured the shared contracts.** The alphabet activity's letter, image and choices now form one state value; setup controls receive the existing activity props directly. Unused aliases and a redundant artwork-completeness scan were removed. Action-card utility icon fallback and inline-add selection were simplified. Publicly used asset resolvers and deployment entrypoints were retained.

## Measurement and reproduction

The baseline is the working tree at the start of this request, including pre-existing uncommitted UI and Fractions work. Comparing against the last commit would incorrectly credit or blame this refactor for that work. Source snapshots, raw artifacts and the comparison are retained under `output/quality-review-2026-09-23/`; normal current artifacts are under `target/analysis/` and `target/functions-analysis/`.

Complexity and effort are sums of callable records; LOC sums file records; locality and leverage sum risk scores, where lower is better. These are comparison aids, not official global Lens scores, runtime benchmarks or estimates of developer hours. Nested callable effort can overlap. The leverage heuristic counts assertions, including literal assertions: replacing inferred timing objects with an explicit union accounts for part of its improvement. Runtime performance and test coverage were not measured.

The project command `node scripts/quality-gate.mjs 0000000` exercised the full gate in an isolated copy preserving Git history. Final artifacts were also generated directly in this working tree using the unchanged Lens `loadConfig`/`runAudit` API with `{ base: '', gate: 'all' }` for each config. An explicit empty base prevents the automatic `origin/main` fallback from narrowing the audit to changed hunks. The CLI's ordinary `measure all --config ...` reproduces the metrics and test evidence.

All application changes remain uncommitted for review. No deployment was performed.
