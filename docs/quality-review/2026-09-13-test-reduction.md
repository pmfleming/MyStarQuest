# Test suite reduction — 13 September 2026

The starting point is commit `8e12e0d`. A fresh baseline run passed all 245 Vitest cases. Adding the three Node quality-gate cases and the sign-in scenario executed in three Playwright browsers gives **251 runnable cases**. Parameterized rows and browser projects count as separate cases; describe blocks, assertions, fixtures, and helper functions do not.

The nearest whole-number target is `round(251 × 0.67) = 168`. The final suite contains **168 cases**, a reduction of **83 (33.07%)**, retaining **66.93%** of the baseline.

| Runner                                 |  Before |   After | Removed |
| -------------------------------------- | ------: | ------: | ------: |
| Vitest                                 |     245 |     162 |      83 |
| Node quality checks                    |       3 |       3 |       0 |
| Playwright (Chromium, Firefox, WebKit) |       3 |       3 |       0 |
| **Total**                              | **251** | **168** |  **83** |

The change removes 1,146 net lines from test files. Production code, dependencies, test discovery, runner settings, and quality thresholds are unchanged. No cases were skipped, marked todo, or hidden behind narrower discovery rules.

## Preserved critical checks

- Persistence and balances: stored reward cost, transactional awards, replay deduplication, child ownership, balance clamping, reset/retry, snapshot ordering, remote profile rollback, and coalesced writes.
- Activity lifecycle: completion only after the final answer, duplicate answer suppression, failure-disabled retries, reset/unmount cancellation, dinner expiry, and reset during final-bite animation.
- Data failures: invalid documents, malformed weather/calendar data, retries, stale responses, cache expiry, abandoned requests, and city-local midnight.
- Resource lifecycle: shared texture generation, worker failure/timeout fallback, late completion after disposal, scene ownership, observer teardown, clock cleanup, and drag cancellation.
- Authentication and gate behavior: sign-in routing in all three browsers; the pinned TypeScript Lens still accepts inherited debt and rejects a newly introduced blocker.

This deliberately reduces exhaustive cosmetic, catalog, compatibility, and configuration cross-product coverage. It does not claim unchanged statement or branch coverage percentages. Remaining tests protect the behavioral contracts above; numeric test count alone is not a coverage metric.
