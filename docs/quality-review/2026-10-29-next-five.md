# Five quality improvements 29 October 2026

Implemented five improvements in value order, prioritizing a real write-boundary validation gap and child-access reliability before reuse and dependency cleanup. Each improvement has its own commit. The previous pending story, artwork, and quality-refactor changes remain unstaged; partially modified files were staged by the new changes only.

The same latest upstream Quality Lens revision, `233239b623b67df9c772d7ac3602740fb9de3f12` (0.3.0), was verified against upstream `main`. No policies, discovery roots, exclusions, thresholds, or suppressions were changed.

## The five changes

1. **Reject coerced shared-operation fields — `a034c94`.** Collection names, document modes, date keys, task types, and water levels previously admitted arrays or objects through `String(value)`. Such values could pass validation while failing the strict string comparisons used by routing and authorization. The validators now use primitive checks and strict enum membership. All five new unit regressions failed before the fix and pass afterward. An emulator regression rejects forged child-collection values for both the authorized child and a sibling and verifies unchanged balances. All 14 sharing-emulator tests pass.

2. **Validate child-access grants before subscribing — `d3cbd72`.** Grant parsing now shares the scope ID/version contract and admits only active grants with valid IDs and nonnegative safe integer versions. Empty IDs, slash-containing paths, negative/fractional/unsafe versions, and inactive grants are skipped before creating profile listeners. Malformed grants cannot leave the picker waiting for invalid profiles. Existing subscription invalidation, revocation, and ownership-isolation tests still pass; focused validation passed seven tests.

3. **Use one unbiased learning-choice shuffle — `1349d14`.** Animal, alphabet, and spelling choices now share a non-mutating Fisher–Yates shuffle instead of random sort comparators. The shuffle preserves duplicates, null/undefined values, object identity, and caller-owned arrays. A deterministic regression enumerates the six equally likely draw paths for three items and verifies all six permutations, avoiding statistical flakiness. Shuffle/alphabet and animal-session tests pass.

4. **Share preview dismissal and focus ownership — `27cf57c`.** Calendar weekday previews, reward previews, and expandable agenda rows use one dismissal lifecycle. It owns outside/focus/Escape listeners, aborts them together, reads the latest callback without resubscribing, and optionally restores focus only while the layer still owns it. The calendar's active-day key and the reward's click-away behavior are retained. Ten focused component tests pass, including StrictMode replay, fresh callbacks, listener cleanup, and avoiding focus theft. Native browser checks pass for both themes in Chromium, Firefox, and WebKit.

5. **Separate theme identity from UI artwork — this commit.** Theme identifiers and their guard now live in an asset-free data module. Profile parsing, theme selection, invitation handling, and data-side type consumers use that module directly. The existing UI exports remain compatible. A regression makes UI theme metadata throw if loaded by profile parsing, verifies both supported saved themes, and rejects prototype names, coerced values, and unsupported themes. Five focused tests and the final full checks pass.
