## Changes

- Consolidated cartoon/photo/reconstruction behavior in `TrainingPhotoPortrait`. Removed the duplicate dinosaur portrait and unused presentation branches. Kept collection names and artwork in the existing nearby metadata module. Derived play props from the session's actual return type instead of maintaining a second field list.
- Moved fact-card and repeat-control styles to scoped CSS with per-instance theme variables. A single repeat-control render handles both themes, so colocated controls no longer overwrite each other's interpolated global theme rules. Preserved pointer, keyboard, picture switching and zoom behavior.
- Reused `NumberStepper` in Arithmetic, Large Numbers and Place Value while keeping bounds and answer state in each activity. Consolidated subtraction counter artwork into `MathCounter`.
- Replaced unchecked image-map and event-target assertions with typed APIs or runtime narrowing. Dinosaur profile IDs now select a statically checked clue dictionary, eliminating a redundant runtime missing-key guard. Removed unused exports.
- Fixed the gesture test's existing lazy-loading race by awaiting dynamic imports before exercising timer-driven gestures.

Locality improves modestly: removing the duplicate portrait reduces the total, while the consolidated portrait's own risk rises from 40 to 52 because it handles more image sources. Shared steppers improve actual reuse without moving domain state out of its activity. Leverage risk falls in AnimalTester (36 to 0), LearningNavigation (48 to 24), creaturePhotos (12 to 0), and themeAssets (32 to 0).

The remaining clone is AppErrorBoundary's symmetric listener registration/removal. Keeping those lifecycle operations explicit is clearer than adding an abstraction solely to eliminate the finding.
